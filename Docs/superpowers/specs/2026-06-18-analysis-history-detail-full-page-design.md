## 目标

- 将“解析历史详情”从弹窗改为完整页面，在主内容区域正常展示
- 支持直接复制链接访问详情页
- 保持现有功能不丢：基本信息、当前标签、解析结果打标、调试信息、解析文本/摘要、导出
- 保持“手动触发打标”规则：打开详情页不触发模型调用；候选必须点击生成

## 入口与路由

- 新增路由：`"/video/analysis/history/:analysisId"`
- 历史列表按钮“查看 / 打标”改为跳转到上述路由

## 页面结构

### 1) 列表页（"/video/analysis"）

- 保留现有解析页面与解析历史列表
- 点击历史项“查看 / 打标”后，跳转到详情页

### 2) 详情页（"/video/analysis/history/:analysisId"）

- 顶部操作区
  - 返回按钮：优先 `navigate(-1)`；如果无上一页则回到 `"/video/analysis"`
  - 标题：`解析结果详情 #<analysisId>`（如能拿到视频标题则拼接显示）
- 主内容区（复用原弹窗的内容块）
  - 基本信息（模板、创建/完成时间、处理时间、模型、Tokens、状态）
  - 当前标签（复用 `VideoTagsSummary`）
  - 解析结果打标（复用 `AnalysisDerivedTaggingPanel`，默认候选为空，点击生成才调用）
  - 调试信息（复用现有展示）
  - 解析结果正文/摘要（可导出）

## 状态与数据加载

- 详情页通过 `analysisId` 调用既有接口：`GET "/video-analysis/{analysisId}"`
- 详情页内部不依赖列表页的 state（避免刷新/直达链接时丢数据）
- 返回按钮不强依赖列表页状态；若需要保留列表分页/筛选，后续可通过 query 参数扩展（本次先不做）

## 删除/重试等行为

- 若原弹窗内存在“重试/导出/删除”等操作：
  - 按原逻辑迁移到详情页按钮区
  - 删除后跳回列表页并提示

## 测试策略

- 前端：
  - 新增/更新路由测试：历史列表点击“查看 / 打标”会跳转到详情页路径
  - 详情页渲染：能加载并展示基本信息、当前标签、解析结果打标区块
  - 保持“打开详情页不自动生成候选”用例

## 验收标准

- 历史详情不再以弹窗形式出现，而是在主内容区域展示完整页面
- 详情页 URL 可复制，刷新后仍可正常打开
- 候选标签无残留：打开详情页时候选区为空；点击生成才出现候选
