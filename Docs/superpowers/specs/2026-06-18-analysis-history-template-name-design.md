# 2026-06-18 解析历史列表增加模板名称显示

## 目标

- 在解析历史列表中，为每条历史记录增加“使用的模板名称”显示。
- 保持最小改动，优先复用前端已加载的模板列表，不新增后端接口字段。

## 方案

- 前端基于历史记录已有的 `template_id`，与页面初始化时已加载的模板列表进行本地映射。
- 在解析历史列表每条记录的摘要区域新增一行：
  - 有模板：`模板：{template.title}`
  - 无模板：`模板：未使用模板`

## 非目标

- 不修改后端历史列表接口。
- 不新增模板详情查询接口。

## 风险与兼容

- 若模板已被删除或当前前端未加载到该模板，则回退显示：`模板：未使用模板`。
- 仅为展示增强，不影响现有解析历史逻辑。

## 测试

- 前端测试覆盖：
  - 有 `template_id` 且可映射到模板名称时正确显示
  - `template_id` 为空时显示 `模板：未使用模板`
